# libtdjson for linux

version: 1.8.67

compatible with docker image smokost/ubuntu20tdlib:1.8.67

## Pre-built libraries

`libtdjson_arm64.so` is an ARM64-only build. It was compiled in an Ubuntu
environment running under Android Termux and is intended for Linux systems
with an ARM64 processor. It is not compatible with x86 or x86_64 hosts.
